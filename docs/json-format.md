# Revu Quote Builder — JSON file reference

Revu Quote Builder writes two kinds of JSON file:

| File | Made by | `kind` |
|---|---|---|
| **Saved quote**, e.g. `Q-26-1001 Mel's Drive In.json` | **Save quote** (or Ctrl+S) | `revu-quote-builder/quote` |
| **Settings backup**, e.g. `revu-quote-builder-settings 2026-11-24.json` | **Settings → Export settings** | `revu-quote-builder/settings` |

Both are plain UTF-8 JSON. Examples generated by the app are in [`examples/`](examples/):
[`quote-example.json`](examples/quote-example.json) (the Mel's Drive In quote with three alternates and an addendum) and
[`settings-example.json`](examples/settings-example.json).
A machine-readable schema for the quote file is in [`quote-file.schema.json`](quote-file.schema.json) (JSON Schema 2020-12).

---

## 1. Quick start: reading a quote into another program

Read **`summary`**. It holds the calculated results exactly as printed on the proposal and internal take-off:

```js
const file = JSON.parse(text);
if (file.kind !== 'revu-quote-builder/quote') throw new Error('not a quote file');
const s = file.summary;                 // present in version 2+ files
s.quoteNumber;                          // "Q-26-1001"
s.project.name;                         // "Mel's Drive In"
s.totals.baseBid;                       // 17160      (dollars, 2 decimals)
s.lines.forEach(l => console.log(l.scopeOfWork, l.description, l.qty, l.unit, l.material, l.labor, l.total));
s.alternates.forEach(a => console.log(a.name, a.title, a.signedAmount));   // "ADD ALTERNATE #1" ... 3120
```

```python
import json
f = json.load(open("Q-26-1001 Mel's Drive In.json", encoding="utf-8"))
s = f["summary"]
print(s["quoteNumber"], s["totals"]["baseBid"])
for line in s["lines"]:
    print(line["scopeOfWork"], line["qty"], line["unit"], line["total"])
```

**Rules for other programs**

- **Money** is in US dollars as JSON numbers, rounded to cents (`17160` = $17,160.00). Deducts are negative in `signedAmount` and in the material/labor differences of alternates.
- **Dates** are `yyyy-mm-dd` strings (`"2026-11-24"`). Timestamps (`savedAt`, `importedAt`) are ISO 8601 UTC.
- **Lengths and heights** are decimal feet (`8.5` = 8'-6").
- **Units** are `"sf"` (square feet), `"lf"` (lineal feet) or `"ea"` (each).
- `summary` is **read-only output**. Revu Quote Builder ignores it when the file is opened, so editing it changes nothing. To change a quote, edit `quote` (section 4) and re-open the file in the app.
- **Ignore fields you don't know.** New fields may be added in later versions.
- Check `version`. Files saved before the summary existed (`version: 1`) have no `summary`; open and re-save them in the app to add one.

## 2. Top level

```json
{
  "kind": "revu-quote-builder/quote",
  "version": 2,
  "savedAt": "2026-11-24T23:15:14.512Z",
  "summary": { … },
  "quote": { … }
}
```

| Field | Type | Meaning |
|---|---|---|
| `kind` | string | Always `"revu-quote-builder/quote"`. |
| `version` | integer | File format version. `1` = no `summary`; `2` = current. |
| `savedAt` | string | When the file was written (ISO 8601, UTC). |
| `summary` | object | Calculated results (section 3). Read-only; version 2+. |
| `quote` | object | Everything needed to re-open and re-price the quote (section 4). |

## 3. `summary` — calculated results (read this)

| Field | Type | Meaning |
|---|---|---|
| `note` | string | Reminder that this block is read-only. |
| `currency` | string | `"USD"`. |
| `quoteNumber` | string | e.g. `"Q-26-1001"`. |
| `date` | string | Quote date, `yyyy-mm-dd`. |
| `generalContractor` | object | `{ name, attention }`. |
| `project` | object | `{ name, address }`. |
| `constructionType` | string \| null | `"new"`, `"remodel"` or `null` (not specified). |
| `laborRate` | object | The union labor rate used (below). |
| `lines` | array | Line items on the quote, in printed order (below). Lines unticked on the Pricing tab are left out. |
| `totals` | object | Base-bid totals (below). |
| `alternates` | array | ADD / DEDUCT alternates, **not** included in the totals (below). |
| `scopeOfWork` | string | The scope-of-work text as printed. Paragraphs are separated by a blank line (`\n\n`). |
| `notes` | string[] | Notes / exclusions, one per item. |
| `addendaReviewed` | string \| null | e.g. `"No. 1 (10-15-26), No. 2 (10-22-26)"`, `"None issued"`, or `null` if not entered. |
| `incomplete` | object | Counts of things still missing: `linesMissingRates`, `linesMissingCount`, `alternatesIncomplete`. All `0` means the quote was complete when saved. |

### `summary.laborRate`

| Field | Type | Meaning |
|---|---|---|
| `area` | string | `"local"` or `"bayArea"`: which union rate was used. |
| `areaSource` | string | `"projectCity"` (picked from the address) or `"pickedOnQuote"` (forced on the Pricing tab). |
| `city` | string \| null | City read from the project address. |
| `hourlyRate` | number \| null | $/hr used (`null` = that area's rate was not set). |
| `hoursPerDay` | number | Hours per crew-day. |
| `perDiemVehiclePerDay` | number | Per diem + vehicle $ per day. |
| `dayRate` | number | All-in labor cost per crew-day = `hourlyRate × hoursPerDay + perDiemVehiclePerDay`. |

### `summary.lines[]`

| Field | Type | Meaning |
|---|---|---|
| `key` | string | Stable id of the line inside this quote: Bluebeam subject + `|` + height, e.g. `"FRP-8'|8"`. Manual lines start with `manual|`. |
| `scopeOfWork` | string | Printed label, e.g. `"(3) ROOMS @ 8' AFF"`. |
| `description` | string | Material description. |
| `code` | string \| null | Catalog code / SKU. |
| `catalogItem` | string | Catalog item the line is priced as. |
| `bluebeamSubject` | string \| null | Bluebeam markup Subject the line came from (`null` for manual lines). |
| `manual` | boolean | `true` = added by hand on the Pricing tab, not from the takeoff. |
| `unit` | string | `"sf"`, `"lf"` or `"ea"`. |
| `takeoffQty` | number \| null | Quantity measured in Bluebeam (sum of the Waste Sq FT column for sf lines). `null` for manual lines. |
| `qty` | number | Quantity priced (Total SQ for sf lines). May have been typed over `takeoffQty`. |
| `qtyEnteredBelowTakeoff` | boolean | `true` = the priced qty was typed **lower** than the takeoff (flagged in red in the app). |
| `heightFt` | number \| null | Height in feet (sf lines). |
| `linealFt` | number \| null | sf lines: `ceil(qty / heightFt)`; lf lines: `qty`; ea lines: `null`. |
| `count`, `countType` | number \| null, string | Scope count and type, e.g. `3`, `"ROOMS"` (also `AREAS`, `WALLS`, `COLUMNS`, `SOFFITS`, `CEILINGS`, `EA`). |
| `materialRate` | number \| null | Material $ per unit (`null` = not entered). |
| `unitsPerDay` | number \| null | Units installed per crew-day (`null` = not entered; `0` = material only). |
| `laborDays` | number | Crew-days of labor (2 decimals). |
| `material` | number | Material $ = `qty × materialRate`. |
| `labor` | number | Labor $ = `laborDays × dayRate`. |
| `total` | number | `material + labor`. |
| `markupColor` | string \| null | Bluebeam markup colour, e.g. `"#FFFF00"`. |
| `bluebeamRowIds` | string[] | Ids of the takeoff rows in `quote.source.rows` that make up this line. |

### `summary.totals`

| Field | Type | Meaning |
|---|---|---|
| `material` | number | Sum of line `material`. |
| `labor` | number | Sum of line `labor`. |
| `laborDays` | number | Sum of line `laborDays`. |
| `subtotal` | number | `material + labor`. |
| `salesTaxPct` | number | Sales tax % on material (usually `0`). |
| `salesTax` | number | `material × salesTaxPct / 100`. |
| `baseBid` | number | **The quote total** = `subtotal + salesTax`. Alternates are not included. |

### `summary.alternates[]`

| Field | Type | Meaning |
|---|---|---|
| `number` | integer | 1, 2, 3 … (one running number). |
| `name` | string | As printed: `"ADD ALTERNATE #1"`, `"DEDUCT ALTERNATE #2"`. |
| `direction` | string | `"add"` or `"deduct"`. |
| `kind` | string | `"line"` (added scope), `"swap"` (value engineering on a base line) or `"lump"` (typed amount). |
| `title` | string | Text printed on the proposal. |
| `description` | string \| null | Material description (`line` / `swap`). |
| `appliesToLine` | string \| null | For `swap`: the `key` of the base line it changes. |
| `unit`, `qty` | string \| null, number \| null | Quantity of an added line, or the swapped line's quantity. |
| `material`, `labor` | number | `line`: the added material / labor. `swap`: the **difference** from the base line (negative = saving). `lump`: `0`. |
| `salesTax` | number | Tax on the material (difference), if a tax % is set. |
| `amount` | number | Price shown on the proposal, always positive. |
| `signedAmount` | number | `+amount` for ADD, `−amount` for DEDUCT. Base bid + accepted `signedAmount`s = new contract total. |
| `incomplete` | string[] \| null | What was still missing when saved (e.g. `["quantity"]`), or `null`. |

## 4. `quote` — the editable quote (what the app reads back)

These are the **inputs**: the Bluebeam rows, typed values and rate snapshot. Values typed into the app are often stored as **strings** exactly as typed (`"2200"`, `"2.85"`, `"8'"`). Parse them as numbers, allowing `,` and `$`. A missing or empty value means "use the automatic value".

| Field | Type | Meaning |
|---|---|---|
| `number` | string | Quote number, e.g. `"Q-26-1001"`. |
| `numberCommitted` | boolean | `true` once the number was assigned by a save (or typed by hand). |
| `date` | string | `yyyy-mm-dd`. |
| `gc` | object | `{ name, attention }`. |
| `project` | object | `{ name, address }`. The address also selects the union rate area. |
| `constructionType` | string | `"new"`, `"remodel"` or `""`. |
| `notes` | string | Notes / exclusions, one per line (`\n`). |
| `scopeText` | string (optional) | Scope of work typed on the Quote tab. **Absent** = built automatically from the catalog scope of the lines. |
| `validDays` | number | Proposal validity in days. |
| `taxPct` | number \| string | Sales tax % on material. |
| `proposal` | object | GC proposal options: `showSplit`, `lumpSum`, `showUnitQty` (booleans). |
| `internal` | object | Internal take-off options: `showCalc` (boolean). |
| `groupByRoom` | boolean | Split lines by Room/Space. |
| `laborZone` | string | `"auto"` (from the project city), `"local"` or `"bay"`. |
| `source` | object \| null | The imported Bluebeam CSV (4.1). |
| `excludedRows` | object | `{ "<row id>": true }` for takeoff rows unticked on the Import tab. |
| `manualLines` | array | Lines added by hand: `{ id, catalogSubject, qty, height }`. |
| `lineOverrides` | object | Per-line values typed on the Pricing / Quote tabs, keyed by line `key` (4.2). |
| `alternates` | array | Alternate inputs (4.3). |
| `addenda` | array | `{ id, number, date }` (`date` optional, `yyyy-mm-dd`). |
| `addendaNone` | boolean | `true` = "No addenda issued". |
| `rates` | object | Snapshot of the rates the quote is priced with (4.4). |

### 4.1 `quote.source` — the Bluebeam takeoff

| Field | Type | Meaning |
|---|---|---|
| `fileName` | string | Name of the imported CSV. |
| `importedAt` | string | ISO 8601 UTC. |
| `headers` | string[] | CSV column headers as exported by Revu. |
| `rows` | array | Markup rows (below). |
| `subtotals` | array | Bluebeam group subtotal rows (`"FRP-8' (2)"`): same fields plus `count`, `isSubtotal: true`, `detailCount` and `detail_*` sums. Not priced; used for cross-checking. |
| `warnings` | array | Import warnings: `{ level, code, message }`. |
| `autoFilled` | string (optional) | Note shown when project / GC were filled from the file name. |

**Row fields:** `id` (`"r2"`), `line` (CSV line number), `subject`, `baseSubject` (subject without the `(n)` group count), `label`, `room`, `space`, `layer`, `color` (`"#FFFF00"`), `comments`, `page`, `measurement` (decimal feet, or the count for Count markups), `measurementUnit` (e.g. `ft' in"`, `Count`), `sqFt`, `matHeight`, `installHeight` (decimal feet), `installHeightText` (as exported, e.g. `8'` or `LF`), `wasteSqFt`, `rowUnit` (`"ea"` for Count markups, `"lf"` when Install Height says LF, else `null`). Blank cells are `""` for text and `null` for numbers.

### 4.2 `quote.lineOverrides["<line key>"]`

All optional. An absent key means automatic.

| Key | Meaning |
|---|---|
| `qty` | Total SQ / priced qty typed by hand. |
| `height` | Height, feet-inch text (`"9'-6\""`). |
| `materialRate`, `unitsPerDay`, `laborDays` | Rates typed for this line. `laborDays` replaces units/day. |
| `rooms`, `roomNoun`, `scopeNote` | Scope-of-work count, type and note. |
| `scopeLabel` | Whole scope-of-work label typed by hand. |
| `description` | Material description typed by hand. |
| `scope` | Older files only: per-line scope paragraph (now `quote.scopeText`). |
| `excluded` | `true` = line left off the quote. |

### 4.3 `quote.alternates[]`

| Field | Used by | Meaning |
|---|---|---|
| `id`, `kind`, `title` | all | `kind`: `"line"`, `"swap"` or `"lump"`. |
| `catalogSubject`, `qty`, `height`, `materialRate`, `unitsPerDay`, `laborDays` | `line` | The added line. |
| `lineKey`, `qty`, `materialRate`, `unitsPerDay`, `laborDays` | `swap` | Base line `key` and the values that change. Blank = same as the base line. |
| `direction`, `amount` | `lump` | `"add"` / `"deduct"` and the dollar amount. |

### 4.4 `quote.rates` — rate snapshot

| Field | Meaning |
|---|---|
| `catalog[]` | Catalog items: `subject`, `code`, `description`, `scope`, `unit` (`sf`/`lf`/`ea`), `materialRate`, `unitsPerDay` (`null` = typed per quote), optional `roundTo`. |
| `labor` | `hourlyRate` (Local), `bayAreaHourlyRate`, `hoursPerDay`, `dailyAdder` (per diem + vehicle $/day), `dayRounding` (`none` / `half` / `whole`). |
| `quantity` | `source` (`wasteSqFt` / `sqFt` / `calc`), `roundTo` (0 = none), `wastePct`. |
| `subjectMap` | Bluebeam subject → catalog subject (`"__ignore__"` = leave off the quote). |
| `rateEntry` | `"manual"` (material $ and units/day typed per line) or `"catalog"` (pre-filled from the catalog). |
| `bayAreaCities` | Cities that get the Bay Area rate. |
| `priceList` | Last imported Excel price list: `{ fileName, sheetName, importedAt, itemCount }` or `null`. |

## 5. Settings backup file

```json
{ "kind": "revu-quote-builder/settings", "version": 1, "exportedAt": "2026-11-24T23:15:15.002Z", "settings": { … } }
```

`settings` has the same shapes as `quote.rates` (`catalog`, `labor`, `quantity`, `subjectMap`, `rateEntry`, `bayAreaCities`, `priceList`), plus:

| Field | Meaning |
|---|---|
| `version` | Settings format version (currently `5`). |
| `company` | `name`, `address`, `phone`, `email`, `license`, `logoDataUrl` (image data URL or path), `logoLayout` (`banner` / `beside`). |
| `terms` | `validDays`, `notes[]` (default notes / exclusions), `taxPct`. |
| `proposal`, `internal` | Default print options (as in the quote). |
| `quote` | Numbering: `prefix` (`"Q-"`), `includeYear`, `startNumber` (`1001`), `counters` (`{ "2026": 1002 }`: the next number per year, or `"all"` when the year is off). |

## 6. Versions

| File | Version | Change |
|---|---|---|
| Quote | 1 | Original format (no `summary`). |
| Quote | 2 | Adds the read-only `summary` block. |
| Settings export | 1 | Envelope `{ kind, version, exportedAt, settings }`; the settings themselves carry their own `version`. |
